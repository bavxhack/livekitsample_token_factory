LiveKit-Konferenz im iFrame

Dieses POC folgt jetzt dem von dir gezeigten Bash-Script: Es baut denselben JWT-Header, denselben Payload-Stil, signiert per HS256, sendet { "token": "..." } an die Token-Factory und akzeptiert als Antwort entweder direkt eine fertige LiveKit-URL oder einen JWT.

Wird nur benutzt, falls die Token-Factory keinen kompletten Link, sondern nur einen JWT zurückliefert.

Hinweis: Das Script aus deinem Beispiel berechnet zwar einen Ablaufzeitpunkt, schreibt ihn aber nicht in den Payload. Dieses POC übernimmt deshalb den gleichen Payload-Stil und fügt exp standardmäßig nicht ein.

Bereit. Bitte Daten prüfen und Konferenz starten.
Noch kein Payload erzeugt.
Noch kein Token erzeugt.
