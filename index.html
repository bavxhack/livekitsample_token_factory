LiveKit-Konferenz im iFrame

Dieses POC baut den JWT exakt im dokumentierten LiveKit-Format, signiert ihn im Browser per HS256, schickt ihn an die Token-Factory und startet danach die Konferenz mit dem zurückgegebenen JWT im iFrame.

Hier wird am Ende automatisch ?jwt=... angehängt.
Nur für diesen POC im Frontend erlaubt.
Wird automatisch von http:// bzw. https:// bereinigt.
Meetling wird automatisch als leerer String in den Payload geschrieben.

Die Identity wird automatisch erzeugt im Format meetling_<slug(username)>_<timestamp>_<random>.

Bereit. Bitte Konfigurationsdaten eintragen und Konferenz starten.
Noch kein Payload erzeugt.
Noch kein Token erzeugt.
